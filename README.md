# ⚙️ dotfiles

Personal development machine config & toolbox.

## Directory

| &emsp;&emsp;                                                             | Where                   | What                                                                                                                                                                                         |
| ------------------------------------------------------------------------ | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <img src="./misc/docs/assets/apple.svg" height="18" align="absmiddle">   | [`macos/`](./macos)     | Setup scripts, configuration, & documentation for my macOS systems.                                                                                                                          |
| <img src="./misc/docs/assets/linux.svg" height="18" align="absmiddle">   | [`linux/`](./linux)     | Linux config -- Debian 13 + KDE Plasma setup on an encrypted LUKS2 + LVM disk. Includes a personally-customized full Debian 13 installation script, my system config, & maintenance scripts. |
| <img src="./misc/docs/assets/toolbox.svg" height="18" align="absmiddle"> | [`toolbox/`](./toolbox) | Reusable tools, scripts, & snippets to run or copy into other projects.                                                                                                                      |

## Notes

- My macOS and Linux setups share no config. Duplication is deliberate -- my
  usage on each platform diverges enough that abstracting over the differences
  would cost more than it saves.
